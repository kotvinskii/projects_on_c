Данный проект представляет вам ккалькулятор, умеющий делать алгебраические действия с двумя числами в консоле вашей ОС. Он представляет 16 функций, а именно: сложение, вычитание, умножение и деление двух чисел, 
возведение числа в степень, вычисление факториала для числа, вычисление sin, cos, tg и т.д. Делал проект на с++ 20 стандарте и компиляторе MSVC, в VS(23 версии). Надеюсь на положительный фитбек:)
